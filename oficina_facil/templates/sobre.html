SOBRE O PROJETO

Oficina Fácil

O Oficina Fácil é um sistema web acadêmico desenvolvido para apoiar a rotina de uma oficina mecânica.

A aplicação permite organizar clientes, veículos, catálogo de serviços e ordens de serviço, mantendo o histórico dos atendimentos.

Tecnologias

Python · Flask · SQLite · SQL nativo · HTML · CSS · Jinja2
